Core Capabilities

Engineered for Real-World Cybersecurity

javax.crypto.Cipher

AES-256-GCM Encryption

Uses authenticated encryption (AES/GCM/NoPadding) with 128-bit authentication tags and 12-byte random IVs to ensure confidentiality and tamper resistance.

PBKDF2WithHmacSHA256

Hardened Key Derivation

Master passwords undergo 65,536 iterations of PBKDF2 with unique 16-byte cryptographic salts to protect against offline brute-force and dictionary attacks.

Atomic File I/O

Zero Data Loss Storage

Credentials serialize to an encrypted binary database (securevault.dat) via atomic temporary file swapping, eliminating corruptions on unexpected shutdown.

java.awt.Graphics2D

Procedural Vector Icons

Renders custom vector icons at any DPI scaling without external image files, keeping the standalone JAR lightweight (~138 KB).

Entropy Engine

Real-Time Security Audit

Scans the repository for weak passwords, reused keys across services, and stale accounts (>90 days), with one-click direct update workflows.

Zero Cloud / Offline

Zero-Knowledge Privacy

No telemetry, no external HTTP calls, no cloud tracking. Master keys and decrypted entries reside exclusively in temporary RAM.

Object-Oriented Architecture (OOPJ)

Design Principles & Patterns Applied

1. Encapsulation

Sensitive master passphrases, IVs, and decrypted records are tightly encapsulated within DatabaseManager and zeroed out on vault lock.

2. Inheritance & Polymorphism

Custom UI components extend Swing primitives (ScrollablePanel, CustomButton, CustomTextField) with specialized rendering.

3. Abstraction

High-level UI panels communicate exclusively via VaultService and AuditReport, completely decoupling business logic from crypto.

4. Observer Pattern

Data change listeners ensure instant synchronization between My Vault, Dashboard metrics, and Security Audit scans.
